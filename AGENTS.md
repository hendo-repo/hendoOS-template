# Project Agent Instructions

AOS is an experimental Bun and TypeScript implementation of Agentic OS.

- Use Bun for core framework logic. Document native harness adapters separately.
- Keep configuration, state, and render targets isolated from existing installations.
- Read the active work item and relevant project guidance before implementation.
- Keep changes within the assigned scope. Do not overwrite concurrent work.
- Preserve upstream license and attribution when importing framework content.
- Keep personal identities, private tracker references, machine paths, and credentials out of published files.
- Supply private scanner literals through environment variables; never store them in fixtures.
- Use project-local verification. Report the commands run and any unchecked claims.
- Keep active status in the work tracker and durable knowledge in the designated knowledge store.
- Shared operating-framework changes require explicit authorization.
